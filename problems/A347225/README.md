# 三对孪生素数具有相同的十进制周期增量

**结论**　Lamine Ngom 于 2021 年在 A347225 的注释中猜测，对于 1、2 以外的周期差，最多只有两对孪生素数，并称在十亿以内未见反例。下表三对孪生素数的周期均沿同一方向增加 **1,120,174**，六个素数全部小于 6300 万。它们同时覆盖有向差和绝对差两种读法。A347225 本身列出的是一类半周期孪生素数。[原条目](https://oeis.org/A347225) · [2021 年原始表述](https://github.com/oeis/oeisdata/blob/72c53dd50967a/seq/A347/A347225.seq)

## 有向差的反例

对素数 $p>5$，$1/p$ 的十进制循环节长度 $d(p)$ 等于 10 模 $p$ 的乘法阶，即使 $10^d\equiv1\pmod p$ 的最小正整数 $d$。将差取为 $d(p+2)-d(p)$，可得下表。[周期定义](https://oeis.org/A002371)

| $p$ | $p+2$ | $d(p)$ | $d(p+2)$ | 增量 |
| ---: | ---: | ---: | ---: | ---: |
| 8,401,301 | 8,401,303 | 1,680,260 | 2,800,434 | 1,120,174 |
| 14,935,649 | 14,935,651 | 1,866,956 | 2,987,130 | 1,120,174 |
| 62,729,729 | 62,729,731 | 7,841,216 | 8,961,390 | 1,120,174 |

这三对通过从小到大枚举孪生素数、按有向差分组找到。以下另一组较大的反例通过固定乘法阶的指数得到。

| $p$ | $p+2$ | $d(p)$ | $d(p+2)$ | 增量 |
| ---: | ---: | ---: | ---: | ---: |
| 18,690,068,729 | 18,690,068,731 | 9,345,034,364 | 18,690,068,730 | 9,345,034,366 |
| 24,920,091,641 | 24,920,091,643 | 3,115,011,455 | 12,460,045,821 | 9,345,034,366 |
| 49,061,430,419 | 49,061,430,421 | 7,008,775,774 | 16,353,810,140 | 9,345,034,366 |

这些例子来自一个简单的筛选。若 $a=(p-1)/d(p)$、$b=(p+1)/d(p+2)$，共同增量为 $k$，则 $(a-b)d(p)=bk-2$。固定三组 $(a,b)=(2,1),(8,2),(7,3)$ 后，给定 $k$ 就决定了三对候选整数，分别核验素性和阶即可。

## 十亿以内的绝对差

若按绝对值理解“差”，下表的三对都落在原文报告的 $10^9$ 范围内。它们的绝对差均为 **866,953**。

| $p$ | $p+2$ | $d(p)$ | $d(p+2)$ | 有向差 |
| ---: | ---: | ---: | ---: | ---: |
| 1,733,909 | 1,733,911 | 1,733,908 | 866,955 | −866,953 |
| 3,715,511 | 3,715,513 | 371,551 | 1,238,504 | +866,953 |
| 10,403,441 | 10,403,443 | 2,600,860 | 1,733,907 | −866,953 |

## Lean 怎样验证

对每个候选阶 $d$，证书列出 $d$ 的完整素因子分解，验证 $10^d\equiv1\pmod p$，并对每个素因子 $q\mid d$ 验证 $10^{d/q}\not\equiv1\pmod p$。两者合起来保证 $d$ 是最小正指数。每个候选素数另外给出 Lucas 素性证书，以同样的方法验证某个底数具有阶 $p-1$。源码证明二进制模幂运算正确，并由 Lean 内核检查所有数值等式。[Lean 源码](A347225.lean) · [mathlib 的 Lucas 判据](https://github.com/leanprover-community/mathlib4/blob/v4.24.0/Mathlib/NumberTheory/LucasPrimality.lean)

本目录固定 Lean 与 mathlib 4.24.0。解压后在其中运行

```sh
lake exe cache get Mathlib.NumberTheory.LucasPrimality Mathlib.Tactic.NormNum.Prime
lake env lean A347225.lean
```

主定理为 `A347225.ngoms_claim_false`、`A347225.directed_counterexample_below_billion` 和 `A347225.absolute_counterexample_below_billion`。三者的 `#print axioms` 均只列出 `propext`、`Classical.choice` 和 `Quot.sound`。
