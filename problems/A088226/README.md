# A088226 最近平方数公式的下标勘误

OEIS 从 $a(1)=0$ 起编号。Ralf Stephan 在 2013 年的注记中提出，$2a(n)$ 等于 $n$ 到一个完全平方数的最小偶数距离。**反例是 $n=5$**。递推给出 $a(5)=0$，与 $5$ 同奇偶的最近平方数是 $1$ 和 $9$，距离都是 $4$。把注记中的 $n$ 改成 $n-1$ 后，公式对所有 $n\ge1$ 成立。[OEIS 条目](https://oeis.org/A088226) · [固定版本的递推、注记、分块公式和程序](https://github.com/oeis/oeisdata/blob/75e849f306e5850b3ea1a26e65577cd9dbcb2dc6/seq/A088/A088226.seq#L5-L10)

## 定理

令 $q$ 遍历非负整数，完全平方数包括 $0$。两整数之间的距离为偶数，当且仅当它们同奇偶。按条目的下标，有

$$
2a(n)=\min_{q^2\equiv n-1\pmod 2}|(n-1)-q^2|,\qquad n\ge1.
$$

原注记有无穷多个反例。每个 $k\ge1$ 都给出 $a(k^2+1)=0$，而 $k^2<k^2+1<(k+1)^2$，所以 $k^2+1$ 到任意平方数的距离均为正。

## 递推证明

令 $b(t)=a(t+1)$。前三项为 $0,0,1$。对 $0\le m\le k$，置 $t=k^2+2m$，连续三项为

$$
(b(t),b(t+1),b(t+2))=(m,k-m,m+1).
$$

初始情形 $k=m=0$ 成立。若 $m<k$，把三项代入两次递推，接下来的两项分别为 $k-m-1$ 和 $m+2$，这就把 $m$ 增加了 $1$。当 $m=k$ 时，末三项为 $(k,0,k+1)$，下一项为 $1$。由于 $(k+1)^2=k^2+2k+1$，从 $(k+1)^2$ 起的三项恰为 $(0,k+1,1)$，即下一块的起点。双重归纳覆盖全部下标。

取 $t=n-1$ 和 $k=\lfloor\sqrt t\rfloor$。当 $t=k^2+2m$ 时，$b(t)=m$，$k^2$ 的距离是 $2m$。比 $k^2$ 更大的候选同奇偶平方数至少为 $(k+2)^2$，距离至少 $2k+4\ge 2m$。当 $t=k^2+2m+1$ 时，$b(t)=k-m$，$(k+1)^2$ 的距离是 $2(k-m)$。对 $k\ge1$，更小的候选平方数至多为 $(k-1)^2$，其距离至少 $2(k+m)\ge 2(k-m)$。同一侧更远的平方数都不会减小距离。

## 形式化验证与来源

[A088226.lean](A088226.lean) 从三项递推定义序列。`literal_refutation` 在 $n=5$ 否定原注记，`refutation_at_squares` 验证无穷反例族，`shifted_formula` 验证修正后的全称公式。源码同时构造使距离达到最小值的平方数，并证明对其他每个合格平方数的下界。在 Lean 4.24.0 和 mathlib v4.24.0 环境运行以下命令即可复核。

```sh
lake env lean A088226.lean
```

核查原始记录时，OEIS 同页已经列出了上述分块公式。Stephan 给出的 PARI 公式以 $0$ 为第一个输入时也与该序列相符。按编号、作者、英文注记和偏移关键词检索公开网页，未找到单独指出这处下标差异的证明。这里交付的是对原注记的反例及从递推到修正公式的形式化证明。已有公式和程序的历史归属见[原始记录](https://github.com/oeis/oeisdata/blob/75e849f306e5850b3ea1a26e65577cd9dbcb2dc6/seq/A088/A088226.seq#L5-L10)。
